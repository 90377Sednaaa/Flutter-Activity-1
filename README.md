# Flutter Activity 1 — Pavlova Recipe Showcase

A Flutter activity project that displays a single dessert recipe (Pavlova) with a rating row, description, and recipe specs. Built with Material 3.

## Features

- 🍰 **Recipe hero image** — full-width Pavlova dessert photo
- ⭐ **Interactive star rating** — 4 of 5 stars filled (amber accent)
- 📝 **Recipe description** — background about the Pavlova dessert
- ⏱️ **Recipe specs** — PREP / COOK / FEEDS info row
- 🧪 **Widget tests** — app structure, app bar title, star logic, and image rendering

## Getting Started

### Prerequisites

- [Flutter SDK](https://flutter.dev/docs/get-started/install) (Dart SDK ^3.13.0)
- Android Studio, VS Code, or your preferred Flutter IDE

### Run the app

```bash
flutter pub get
flutter run
```

### Run the tests

```bash
flutter test
```

## Project Structure

```
lib/
  main.dart        # App entry point and theme
  pavlova.dart     # Recipe screen (Pavlova) with rating row and specs
assets/
  Pavlova.jpg      # Payload recipe image
test/
  widget_test.dart # Smoke tests for the app
```
